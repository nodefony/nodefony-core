### 🔴 FRICTION MAJEURE — permissions (à retenir absolument)
Le user a exprimé 3× sa frustration : "tu demande encore des validations", "je peux pas te faire confiance", "ça marche pas". **Cause racine** : chaque Write/Edit/Bash non pré-approuvé déclenche un prompt manuel. En mode "autonomie nuit", c'est rédhibitoire.
- **Leçon 1** : AVANT toute session autonome, vérifier/ajouter `Write(*)`, `Edit(*)`, `Bash(bash .claude/skills/*)` etc. dans `.claude/settings.local.json`.
- **Leçon 2** : ne PAS poser d'AskUserQuestion quand le user a demandé l'autonomie — il l'a vécu comme une trahison de la consigne.
- **Leçon 3** : consolider les workflows multi-commandes en SCRIPTS (1 approbation au lieu de N). Pattern appliqué à start-nodefony-server → à généraliser.

### Recommandations consolidées (pour le mode consolidation futur)
1. **Skill `setup-autonomy`** — vérifie + ajoute les permissions larges au début d'une session autonome. Éviterait toute la friction de cette session.
2. **Pattern "skill = script"** — tout skill qui enchaîne 3+ commandes Bash doit fournir un `.sh` exécutable, pas une liste de commandes inline. Réduit drastiquement les prompts.
3. **for/compound Bash** — les patterns `for *` / `cmd1 && cmd2` matchent mal les permissions. Préférer commandes simples OU script dédié.
