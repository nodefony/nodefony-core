## Recommandations

1. Un banc de contrat partagé s'importe par chemin relatif : **compter les
   niveaux depuis le fichier**, pas depuis le module.
2. Avant `git stash`, vérifier qu'aucun lock ne traîne ; après, relire
   `git status` (un stash partiel est pire qu'un stash raté).
3. Quand un test passe seul et échoue en suite : **suspecter le banc, pas le
   code** — et le prouver en isolant deux fichiers (ici : 3 bancs token
   ensemble → 11 échecs, sans aucun fichier du diff en cours).
