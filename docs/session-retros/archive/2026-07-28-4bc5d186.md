## Ce que la journée a appris

- **Le danger d'un banc n'est pas le rouge, c'est le faux rouge** : il fait dégrader le produit
  pour lui plaire. Évité de justesse sur T10 — j'allais « corriger » un code qui répondait 200.
- **Le décor décide de ce qu'on mesure.** En isolé, l'agent n'écrit plus `@injectable` : il le
  tenait de nos sources. `@injectable` n'apparaît **nulle part** dans une app fraîche.
- **Un obstacle d'environnement se lit comme un échec d'agent** (`timeout` absent sur macOS).

## Coûts évidents

- Trois qualifications de faux positifs faites à la main (lecture de diffs, démarrage du serveur,
  frappe d'un endpoint) — exactement le travail que l'auto-contrôle livré rend inutile.
- Un run complet ≈ 45 min pour 12 tâches ; le monitor tombé une fois (le run, lui, continuait).

## 🔴 Ce que j'ai eu faux

- **Attribution inventée dans un message de commit** : j'ai écrit que les docs périmées avaient
  égaré l'agent — son transcript montre qu'il n'a ouvert aucun fichier du framework.
- **Déduction non vérifiée** : « le service n'est pas au conteneur donc la route casse » — elle
  répondait 200 (auto-résolution par `design:paramtypes`).
- **Lecteur de rapport écrit avec la mauvaise clé** (`ok` au lieu de `pass`) → j'ai cru un instant
  que le rapport JSON était faux.
