# Session retro — 2026-08-02 — 44c2de5b

## Focus

Reprise sur le gate « le code de l'`AGENTS.md` compile ». Interruption à chaud :
la forge était rouge. Les deux se sont rejoints — même cause de fond, le
scaffold que le dépôt n'utilisait pas.

## Fait

- **Forge réparée** : `create module` en layout dépôt rendait un `package.json`
  sans `devDependencies` → aucune arête de build, `@nodefony/devkit` construit
  avant `nodefony`, quatre workflows sur `Cannot find module … dist/node/bundler`.
  Gabarit corrigé, garde `nodefony check` étendue (`peer-only-sibling`), deux
  dettes réelles soldées (drizzle → framework, framework → http).
- **Gate `AGENTS.md`** : les expressions citées (inline dans la prose, pas en
  blocs) sont replacées dans leur classe de base et compilées.
- **Gate lint** : la grille du dépôt s'applique à l'app générée, l'étape se
  prouve d'abord sur un témoin fautif.
- `--deny-warnings` déplacé du workflow vers le script racine.

## Coûts évidents

- Le banc rejoué 5 fois (~1 min chacun) — inévitable, chaque passe éprouvait un
  état différent du gate. Le mode `--keep` a évité une 6ᵉ passe.
- Une restauration à faire après un débranchement destructeur (voir ci-dessous).
- Deux commandes perdues sur des réflexes déjà connus (`cd` relatif, `rg -r`) :
  les gardes du dépôt les ont interceptées, coût nul mais bruit réel.

## Ce qui a marché

- **Vérifier la prémisse avant la cause**, deux fois : la CI affichait
  `oxlint --deny-warnings` alors que le script racine ne le portait pas — le
  workflow passait l'option en argument. Et mesurer `turbo --dry=json` a donné
  la cause exacte en une commande, là où lire les manifestes aurait supposé.
- **L'automate avant le modèle** : un `jq` sur les 19 manifestes a rendu la liste
  exhaustive des frères non déclarés ; le sous-agent (`haiku`, lecture seule) n'a
  servi qu'à relever les logs de la forge — le travail pour lequel il est fait.

## Recommandations

1. **Faire prouver un gate par un témoin AVANT de lui faire rendre un verdict** —
   généralisable à tout outil externe branché dans un banc.
2. **Borner par construction tout effacement sur chemin calculé** — la prudence
   de qui édite ne suffit pas, un débranchement suffit à la contourner.
3. Prochaine cible du même fil : le banc ne joue pas `create front`, et le mode
   isolé (tarballs) n'a pas été rejoué ce soir.

## Patterns récurrents (déjà gérés)

- ✅ « un outil qui ne sert pas le dépôt qui le publie n'est éprouvé par
  personne » — vu 2×, désormais confirmé à grande échelle.
- ✅ « un gate qu'on n'a jamais vu échouer n'est pas un gate » — appliqué 4× ce
  soir, et c'est le débranchement qui a révélé le défaut destructeur.
