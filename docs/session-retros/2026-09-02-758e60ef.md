## Fait

- **#148 — la tâche 34 du banc de découvrabilité existe et rend un verdict.** Décor à trois moitiés
  (mode de production du schéma, un compte semé une seule fois, un compte venu d'un fournisseur
  externe dont le semis idempotent révèle un doublon si la recherche casse), juge à dix causes
  nommées, décor RELU avant l'agent. Le juge prend ses faits sur l'application qui tourne **et sur
  une base VIERGE qu'il migre** — la seule preuve que le champ atteigne la production.
- **🔴 Trois défauts du PRODUIT, trouvés en écrivant la tâche.** `nodefony create entity User` — le
  geste que le fichier d'entité PRESCRIT — cassait l'application : table `users` face à un SQL qui
  lit `User` en dur (divergence MUETTE : la recherche par compte externe rend zéro ligne, donc un
  compte de plus à chaque connexion) ; export `AppUserEntity` contre `UserEntity` du générateur,
  donc un `index.ts` qui importe un symbole disparu ; câblage refusé alors que régénérer est le
  geste attendu. Le nom de table devient une donnée du contrat (`USER_TABLE_NAME`), lue par
  l'adaptateur SQL, `queryKit` et le générateur.
- **Axe A — `create controller --role ROLE_X`.** Pose la garde sur la CLASSE et déclare le rôle sous
  `ROLE_ADMIN` dans `roleHierarchy` : les deux gestes vont ensemble, et c'est le second qu'on oublie
  à la main. Refus avant écriture sans `@nodefony/security`.
- **Axe B — deux messages qui nomment le geste.** Une réponse HTML portant un `<script>` en ligne
  sans nonce le DIT au journal en développement (coût nul ailleurs) ; `orm:reset` n'est plus proposé
  quand le mode de schéma n'est pas `auto`, et `create entity` cesse d'annoncer une création au boot
  sur un connecteur qui ne fabrique rien.
- **Axe C — `headers.md` et `upload.md` indexés par SYMPTÔME** dans l'`AGENTS.md` généré, plus le
  piège CSP dans la table des pièges.
- **Tâche 35 « recevoir un fichier »** — une capacité qu'aucune tâche ne mesurait, avec le piège de
  sécurité que la façade du framework porte déjà (le nom client ne doit pas composer la destination).

## Frictions (versées dans RETEX.md)

- Le geste qu'un fichier PRESCRIT n'était joué par personne : trois défauts d'un coup.
- Une garde peut interdire ce que le DÉFAUT produit tout seul (`--table` refusé, `users` écrit).
- Une assertion vraie sur une ancre fausse reste verte (`'"User"'` lisait le nom de l'entité).
- Le décor du banc n'avait pas la migration initiale que je supposais — constaté en le MONTANT.
- Un module qui agit à l'import rend le contrôle de son importateur illisible.
- Une ligne ajoutée à une table markdown casse les quatre variantes du gate de format.
- Une sonde de banc au vieux nom accuse le produit d'un défaut qu'elle vient de créer.
- Un second bloc TSDoc détache le premier : le code compile, la doc de la classe disparaît.
- L'audit prescrivait un générateur pour une tâche qui ne l'exerce pas.
- Composer par-dessus une liste que prettier a réécrite : `["ROLE_USER",, "ROLE_X"]`.
