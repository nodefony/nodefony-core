## Recommandations

1. **MEMORY (forte valeur)** : **pattern « type conditionnel inline »** vs
   overloads paramétrés. Quand on type des méthodes avec des génériques + un
   handler `(payload: T) => void`, les overloads cassent en variance — utiliser
   `<K extends string>(method: K, p: K extends Map ? StrictType : Fallback): R`.
   Permet AUSSI de mélanger contrat applicatif typé + noms système permissifs
   sans 2 signatures.
2. **MEMORY** : tests d'inférence TS = `function _typeOnly() { declare const x; ... }`
   jamais appelée. Mocha lit le fichier sans planter (vu 1 crash dans cette
   session, fix immédiat). À mémoriser en feedback session.
3. **MEMORY** : `noUnusedParameters: true` exige que CHAQUE generic soit consommé
   dans une signature publique. Si un generic n'a pas de surface naturelle dans
   l'interface, le pousser sur le type qui le consomme (ex. `Listen` → `Options`).
4. **GUIDE** : pour les classes paramétrées qui `implements` une interface
   paramétrée, la covariance vers les défauts permissifs (`Class<E,L,A>` → `Iface`)
   NE TIENT PAS si les méthodes utilisent des types conditionnels. Cast minimal
   au site (`this as unknown as IFace`) ou paramétrer l'API en aval.
