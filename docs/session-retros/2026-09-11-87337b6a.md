## Coûts évidents

- Trois instruments faux en séance, tous du même genre — l'outil avale ou altère sa sortie :
  un glob zsh qui avorte la commande entière, `npm` qui masque les chemins qu'il rend, un
  `echo $?` après un pipe.
- Un inventaire délégué répercuté sans recompter : cinq fichiers manquants, dont quatre
  vitrines qui affichent la licence dans chaque application générée.
- Un remplacement de masse appliqué à une chaîne qui était AUSSI une clé de données : doublon
  dans un `Set`, et une entrée de `Map` écrasée en silence.

## Recommandations

1. **Le END doit regarder la CI du dernier push** — elle est restée rouge une nuit entière
   sans que personne le sache, et c'est le user qui l'a vue.
2. **Un relevé délégué se recompte d'un motif** avant d'entrer dans une action — la règle est
   écrite dans la description de l'agent, elle n'a pas mordu.
3. **Changer la SOURCE d'une donnée périme les affirmations du TSDoc qui la décrivaient** :
   « dédupliqué par npm lui-même » était vrai de `npm sbom`, faux de `npm query`, et rien ne
   l'a signalé — c'est le user qui a trouvé les doublons.
