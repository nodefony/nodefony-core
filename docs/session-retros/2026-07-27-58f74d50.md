# Session retro — 2026-07-27 — 58f74d50

## Ce qui était prévu

`gateReporter` devait ÉCHOUER en intégration continue au lieu d'afficher un
avertissement dans un job vert, et remplacer les filets `jq` recopiés workflow par
workflow. Fait, avec deux leviers ajoutés en chemin : `proof` (un cas PASSÉ, pas
seulement une variable posée) et `NF_GATES_EXPECT` (l'attente d'une passe).

## Ce qui n'était pas prévu — six gardes qui ne gardaient rien

| Défaut                                       | Origine     | Manifestation                                   |
| -------------------------------------------- | ----------- | ----------------------------------------------- |
| `--reporter` en CLI écrase `test.reporters`  | mon diff    | job vert, garde jamais chargée                  |
| `NF_GATES_ALLOW` filtré par turbo            | mon diff    | exemption écrite, jamais reçue                  |
| `RUN_CLUSTER_E` (coquille recopiée ×5)       | préexistant | bancs cluster inouvrables via `npm test` racine |
| `graceful-shutdown` rangé chez les autonomes | préexistant | workflow rouge à chaque exécution               |
| `CRITIC` traité comme une mort               | préexistant | « a crashé » sur un serveur qui écoutait        |
| **160 fichiers de test hors du cache turbo** | préexistant | « j'ajoute un test, c'est vert » — jamais joué  |

Le dernier est sorti d'une question du user sur le cache. Prouvé dans les deux
sens : un fichier neuf contenant `expect(1).toBe(2)` déposé dans
`security/tests/unit/` donnait `cache hit` et exit 0.

## Coûts évidents

- **Deux de mes propres trous n'ont été vus que par la forge**, pas en local : le
  `--reporter` qui désarme, et l'`env` filtré par turbo. Les deux se voyaient dans
  un journal de job VERT — il a fallu aller y chercher la ligne du rapporteur.
- Une contre-épreuve ratée sur une regex invalide (`-t "config (Zod"`) m'a fait
  croire une seconde à une config cassée. Lire le HAUT du journal, pas la pile.
- L'inventaire « MongoDB = 146 cas muets » repris du `_state` était FAUX :
  `mongodb-memory-server` fait tourner les 168 cas. Corrigé publiquement.

## Recommandations

1. **Un job vert ne dit pas qu'une garde est chargée** — chercher la ligne du
   rapporteur dans le journal fait partie de la preuve, pas du confort.
2. **Une liste recopiée N fois se trompe N fois** — les 5 blocs `env` de
   `turbo.json` portaient la même coquille ; des motifs (`RUN_*`) suppriment la
   classe d'erreur.
3. **Le cache est un gate silencieux** — vérifier ses `inputs` avant de croire un
   vert local.

## Patterns récurrents (déjà gérés)

- ✅ Preuve négative systématique avant de livrer un gate (`feedback_gate_must_bite`).
- ✅ Sous-agent qui PROPOSE, principal qui vérifie : les 5 bancs backplane rendus
  par délégation ont été relus, rejoués et recomptés ici.
