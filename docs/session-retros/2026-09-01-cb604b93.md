## Coûts évidents

- **Le banc de migration coûte cher à jouer** : ~64 s pour les trois moteurs, et il faut PostgreSQL
  et MariaDB montés. Trois passes (sqlite seul, trois moteurs, puis re-passe sur l'état final après
  le débranchement de la garde) — aucune superflue.
- **Deux passes de build complètes** (`npm run build`) parce que le harnais CLI charge le paquet
  BÂTI, pas les sources : débrancher une garde du produit pour la voir mordre exige de rebâtir.
- **Un sous-agent à ~127 k tokens pour un rapport inexploitable** : il a rendu le compte des verdicts
  sans les verdicts. Les dix items refaits à la main en deux minutes.

## Recommandations

1. **Consigne de délégation à durcir** — exiger « une ligne par item, numérotée comme l'énoncé ; un
   résumé chiffré sans le détail vaut zéro ». Le rapport reçu annonçait « 4 VRAI, 4 FAUX, 2 NON
   VÉRIFIABLE » sans dire lesquels.
2. **Lire `include`/`exclude` avant de croire un typecheck** — ou lancer le script `typecheck` du
   paquet, qui sait combien de projets il a. Le `-p tsconfig.json` d'un module exclut ses tests.
3. **Un gate de site se lance sur le site ENTIER** — la forge rend accueil + docs + performance
   avant de vérifier les liens ; un rendu partiel accuse des centaines de faux positifs.
