# Session retro — 2026-08-27 — 0ff06c46

Session courte, ouverte sur une reprise (`nodefony-session` RESUME) et une explication de « S5 DDL
prod ». C'est cette explication qui a déclenché le travail : si le sigle a besoin d'être expliqué,
il n'avait rien à faire dans un ticket.

## Fait

- **36 tickets ouverts repris** : 32 titres réécrits, 23 lexiques posés, 28 corps francisés.
  Les codes de planification internes (`S5`, `R6`, `P10`, `D9`, `R1`, `P6.9d`) remplacés par ce
  qu'ils désignent.
- **Règle gravée** dans `nodefony-ticket` v1.1.0 : le titre se comprend sans connaître le dépôt ;
  trois interdits (code interne, symbole nu, anglicisme quand le français existe) ; le sigle qui
  reste nécessaire se définit dans un bloc `Lexique` en tête de corps, six entrées au plus.
- **Deux scripts versionnés**, rapport seul par défaut, `--write` pour appliquer :
  `scripts/pose-lexique.mjs` et `scripts/francise.mjs`, tous deux lisant `references/lexique.md`
  comme source unique (26 définitions, 21 couples anglais→français, 3 citations figées).
- **Skill rendu atteignable** : entrée dans la table du `CLAUDE.md`, cinq déclencheurs pris des mots
  réellement employés par le user, cinq cas au banc de déclenchement (65 → 70/70, couverture 30/30).

## Coûts évidents

- **La passe entière était évitable.** Le skill existait depuis la veille ; rien ne le nommait,
  donc les tickets ont été écrits sans lui, puis réécrits. C'est le coût d'une règle inatteignable.
- Deux allers-retours sur la sonde du lexique (zone trop large, puis frontières de mot absentes) —
  chacun rattrapé en RELISANT le rendu, pas en croyant le rapport de l'automate.

## Recommandations

1. **Fin de création d'un skill = trois preuves** : cité dans `CLAUDE.md`, un cas au banc, des
   déclencheurs pris de phrases réelles. Sans elles, le skill est écrit mais inerte.
2. **Toute passe de substitution de texte** : borner la zone, exiger les frontières de mot, et
   relire le diff AVANT d'écrire. Le rapport d'un automate de texte ne prouve rien sur le sens.
3. **Le vocabulaire interne s'arrête à la frontière de ma tête** — ticket, commit, page publiée.

## Patterns récurrents (déjà gérés)

- ✅ Gate vu rouge une fois avant d'être cru (banc de déclenchement pointé sur un autre skill).
- ✅ Sortie relue en entier plutôt que par `tail`.
